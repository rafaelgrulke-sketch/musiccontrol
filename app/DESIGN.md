# MusicControl — visual system

Direction: Editorial listening room. Music artwork and listening controls lead; the shell stays quiet.

- Palette: charcoal-green #101311, navigation #141815, player #19221b, pale sage accent #c8e8b9.
- Geometry: compact 6–14px corners; no gradient decoration, no glassmorphism.
- Typography: DM Sans with system fallback; expressive large headings and clear small metadata.
- Layout: permanent desktop navigation, mobile bottom navigation, anchored playback controls.
- Preserve all playback, library, playlist, import, cover and metadata behaviors.
